## 1. Цель работы

Изучить базовые концепции контроля версий, приобрести навыки установки и настройки Git, создания локального и удаленного репозиториев, а также организации структуры для хранения лабораторных работ.

## 2. Краткие теоретические сведения

**Git** - распределенная система контроля версий, позволяющая сохранять изменения проекта и возвращаться к предыдущим версиям.

**Локальный репозиторий** - скрытая папка `.git` на компьютере с историей изменений. **Удаленный репозиторий** - копия проекта на сервере (GitHub). **Коммит** - сохраненное состояние проекта с уникальным идентификатором и описанием.

## 3. Задание (Вариант 5)

Установить и настроить Git, создать локальный репозиторий со структурой `lab_01/main.py`, сделать первый коммит, создать публичный репозиторий на GitHub и отправить в него код командой `git push`.

## 4. Ход выполнения работы

Все команды выполнены в терминале Git Bash.

**Шаг 1. Проверка установки Git**

```bash
git --version
```

![Рисунок 1 - Версия Git](images/step1_git_version.jpg)

**Шаг 2. Глобальная настройка Git**

```bash
git config --global user.name "Бульц Матвей"
git config --global user.email "matvejbulc5@gmail.com"
```

![Рисунок 2 - Настройка имени и e-mail](images/step2_git_config.jpg)

**Шаг 3. Создание локального репозитория и структуры папок**

```bash
mkdir Bults_labs
cd Bults_labs
git init
mkdir lab_01
cd lab_01
touch main.py
```

![Рисунок 3 - Создание папки и инициализация репозитория](images/step3_init_mkdir.jpg)

![Рисунок 4 - Создание файла main.py](images/step3_main_py.jpg)

Структура проекта:

```text
Bults_labs/
    lab_01/
        main.py
```

**Шаг 4. Первый коммит**

```bash
git status
git add main.py
git commit -m "Initial commit: create structure and lab_01"
```

![Рисунок 5 - Состояние репозитория до коммита](images/step4_git_status.jpg)

![Рисунок 6 - Первый коммит](images/step4_commit.jpg)

**Шаг 5. Создание репозитория на GitHub**

На сайте github.com создан новый публичный репозиторий (Public) с именем `Bults_labs`. Опции README, .gitignore и license не выбирались, так как локальный код уже существует.

**Шаг 6. Связывание с GitHub и отправка кода**

```bash
git remote add origin https://github.com/matvey-md/Bults_labs.git
git branch -M main
git push -u origin main
```
