## 2. Краткие теоретические сведения

**Класс и объект:** класс описывает шаблон объекта: набор данных (атрибутов) и операций над ними (методов). Объект (экземпляр) создаётся вызовом класса. Метод `__init__` вызывается при создании объекта и задаёт начальное состояние; первый параметр методов (`self`) — ссылка на текущий объект. Специальные методы `__str__` и `__repr__` задают строковое представление объекта (для `print()` и отладки).

**Инкапсуляция:** сокрытие внутреннего состояния объекта и доступ к нему через контролируемый интерфейс. Атрибуты с префиксом `_` считаются защищёнными (договорённость), с префиксом `__` — приватными (имя искажается интерпретатором). Для проверки значений при присваивании используют свойства (`@property` и `@имя.setter`).

**Наследование и полиморфизм:** наследование позволяет создать класс-потомок, расширяющий или изменяющий поведение базового класса. Обращение к базовому классу выполняется через `super()`. Полиморфизм — возможность работать с объектами разных классов через единый интерфейс: код вызывает один и тот же метод, а конкретная реализация выбирается по типу объекта.

**Оконный интерфейс Tkinter:** Tkinter входит в стандартную библиотеку Python. Приложение строится из окна (`tk.Tk`), виджетов и обработчиков событий. Выполнение программы определяется событиями (нажатие кнопки, перемещение ползунка, таймер), а не последовательным кодом: главный цикл `mainloop()` ожидает события и вызывает обработчики. Используемые виджеты: `ttk.Label`, `ttk.Button`, `ttk.Entry`, `ttk.Scale`, `ttk.Progressbar`, `ttk.LabelFrame`, `tk.Canvas`. Размещение виджетов выполняется методами `pack()` и `grid()`. Связанные переменные `StringVar`, `DoubleVar` автоматически обновляют виджеты при изменении значения (`var.set(...)`).

**Периодические действия:** имитация течения времени организуется методом `after(мс, функция)`; цикл `while` с `time.sleep()` в обработчике недопустим, так как он «замораживает» окно. Диалоги ошибок и предупреждений выводятся функциями `messagebox.showerror()` и `messagebox.showwarning()`.

**Разделение модели и интерфейса:** логика предметной области (классы модели) не должна зависеть от виджетов. Окно приложения — отдельный класс-наследник `tk.Tk`, который хранит ссылку на объект модели, передаёт ему команды и отображает его состояние. Это позволяет тестировать модель без интерфейса.

```python
"""Модель тепловой защиты сервопривода (вариант 5).

Этот модуль НЕ импортирует tkinter: классы модели не зависят от окна,
поэтому их можно проверять просто запуском файла (см. main() внизу).
"""

# Строки-состояния привода. Вынесены в константы, чтобы не ошибиться в написании
NORMAL = "НОРМА"
ALARM = "АВАРИЯ"


class Servo:
    """Базовый класс: сервопривод с нагревом от тока (без защиты).

    Нагрев описывается уравнением теплового баланса первого порядка:
        C * dT/dt = I^2 * R - (T - T_среды) / R_тепл
    где I^2 * R - тепло, выделяемое обмоткой, а второе слагаемое - отвод тепла в среду.
    """

    def __init__(self, name, max_current=6.0, resistance=0.8,
                 r_thermal=2.5, heat_capacity=20.0, t_ambient=25.0):
        # Параметры привода сохраняем в атрибутах объекта (self.* - данные экземпляра)
        self.name = name                    # имя привода (для вывода на экран)
        self.max_current = max_current      # предельно допустимый ток, А
        self.resistance = resistance        # сопротивление обмотки R, Ом
        self.r_thermal = r_thermal          # тепловое сопротивление R_тепл, К/Вт
        self.heat_capacity = heat_capacity  # теплоёмкость C, Дж/К
        self.t_ambient = t_ambient          # температура окружающей среды, °C
        self.reset()                        # задаём начальное состояние (ток 0, привод холодный)

    def reset(self):
        """Возвращает привод в исходное состояние."""
        self._current = 0.0                 # ток, А (с «_» - защищённый атрибут, доступ через свойство)
        self._temperature = self.t_ambient  # привод холодный: температура равна температуре среды

    # ---------- ИНКАПСУЛЯЦИЯ: доступ к току и температуре через свойства ----------
    @property
    def current(self):
        """Чтение тока: servo.current"""
        return self._current

    @current.setter
    def current(self, value):
        """Запись тока: servo.current = 4.0 - срабатывает проверка значения."""
        if not 0.0 <= value <= self.max_current:     # ток вне допустимого диапазона?
            raise ValueError(                         # да - запрещаем присваивание и сообщаем об ошибке
                f"Ток должен быть в диапазоне 0...{self.max_current} А")
        self._check_allowed()               # хук: потомок может запретить менять ток (при аварии)
        self._current = value               # все проверки пройдены - принимаем значение

    @property
    def temperature(self):
        """Температура доступна только для чтения (сеттера нет - присвоить её снаружи нельзя)."""
        return self._temperature

    @property
    def state(self):
        """Состояние привода. В базовом классе защиты нет, поэтому всегда «НОРМА»."""
        return NORMAL

    # ---------- методы-«хуки»: потомок переопределяет их (ПОЛИМОРФИЗМ) ----------
    def _check_allowed(self):
        """Можно ли сейчас менять ток. В базовом классе - всегда можно (ничего не делаем)."""

    def _after_step(self):
        """Реакция на новую температуру после шага. В базовом классе - никакой."""

    def heat_power(self):
        """Тепловая мощность обмотки P = I^2 * R, Вт."""
        return self._current ** 2 * self.resistance

    def step(self, dt=0.1):
        """Один шаг моделирования длительностью dt секунд (метод Эйлера)."""
        # Мощность, уходящая в окружающую среду: (T - T_среды) / R_тепл
        loss = (self._temperature - self.t_ambient) / self.r_thermal
        # Изменение температуры за шаг: dT = (P_нагрева - P_отвода) / C * dt
        d_temp = (self.heat_power() - loss) / self.heat_capacity * dt
        self._temperature += d_temp         # новая температура = старая + изменение
        self._after_step()                  # даём потомку отреагировать (у ProtectedServo - проверить перегрев)

    def __str__(self):
        """Строка для print(servo) и вывода в окне."""
        return (f"{self.name}: I={self._current:.2f} А, "
                f"T={self._temperature:.1f} °C, состояние: {self.state}")


class ProtectedServo(Servo):
    """Потомок Servo: добавляет тепловую защиту (аварийный останов при перегреве)."""

    def __init__(self, name, t_trip=80.0, t_reset=60.0, **kwargs):
        self.t_trip = t_trip      # порог срабатывания защиты, °C
        self.t_reset = t_reset    # температура, ниже которой разрешён сброс аварии, °C
        # super() обращается к базовому классу: он создаст остальные поля и вызовет reset()
        super().__init__(name, **kwargs)

    def reset(self):
        """Расширяет reset() базового класса: дополнительно снимает признак аварии."""
        super().reset()           # сначала выполняем сброс базового класса (ток 0, T = T_среды)
        self._alarm = False       # затем гасим аварию

    @property
    def state(self):
        """Переопределяем свойство: теперь состояние зависит от аварии."""
        return ALARM if self._alarm else NORMAL

    @property
    def alarm(self):
        """True, если защита сработала (только чтение)."""
        return self._alarm

    def _check_allowed(self):
        """Переопределённый хук: при аварии менять ток нельзя."""
        if self._alarm:
            raise RuntimeError("Авария: ток нельзя задать до сброса защиты")

    def _after_step(self):
        """Переопределённый хук: после каждого шага проверяем перегрев."""
        # если аварии ещё нет и температура достигла порога...
        if not self._alarm and self._temperature >= self.t_trip:
            self._alarm = True        # ...фиксируем аварию
            self._current = 0.0       # ...и обесточиваем привод (аварийный останов)

    def reset_alarm(self):
        """Сброс аварии. Разрешён только после остывания привода до t_reset."""
        if not self._alarm:           # аварии нет - сбрасывать нечего
            return
        if self._temperature > self.t_reset:     # привод ещё горячий - сброс запрещён
            raise ValueError(
                f"Сброс невозможен: температура {self._temperature:.1f} °C "
                f"выше {self.t_reset} °C")
        self._alarm = False           # привод остыл - снимаем аварию


def main():
    """Проверка модели без окна: штатный режим, авария, граничные случаи."""
    dt = 0.1                          # шаг моделирования, с

    print("1. Штатный режим: ток 4.0 А, 300 с")
    servo = ProtectedServo("SERVO-1")
    servo.current = 4.0               # задаём ток через свойство (проверка диапазона внутри)
    for _ in range(int(300 / dt)):    # 3000 шагов по 0.1 с
        servo.step(dt)
    print("  ", servo)

    print("2. Перегрузка: ток 6.0 А до срабатывания защиты")
    servo = ProtectedServo("SERVO-2")
    servo.current = 6.0
    t = 0.0
    while not servo.alarm and t < 600:   # считаем, пока защита не сработает
        servo.step(dt)
        t += dt
    print(f"   защита сработала через {t:.1f} с")
    print("  ", servo)

    print("3. Сброс аварии сразу после срабатывания (привод горячий)")
    try:
        servo.reset_alarm()
    except ValueError as err:         # ловим отказ модели, программа не падает
        print("   ошибка:", err)

    print("4. Попытка задать ток во время аварии")
    try:
        servo.current = 2.0
    except RuntimeError as err:
        print("   ошибка:", err)

    print("5. Остывание и сброс аварии")
    t = 0.0
    while servo.temperature > servo.t_reset:   # ток 0, привод остывает
        servo.step(dt)
        t += dt
    servo.reset_alarm()
    print(f"   сброс выполнен через {t:.1f} с после останова")
    print("  ", servo)

    print("6. Недопустимые значения тока")
    for bad in (-0.1, 6.5):
        try:
            servo.current = bad
        except ValueError as err:
            print(f"   I = {bad}: {err}")

    print("7. Полиморфизм: одинаковый step(), разное поведение, ток 6.0 А")
    for obj in (Servo("БЕЗ ЗАЩИТЫ"), ProtectedServo("С ЗАЩИТОЙ")):
        obj.current = 6.0
        for _ in range(int(120 / dt)):
            obj.step(dt)
        print("  ", obj)


# main() запускается только при прямом запуске файла, при импорте в окно - нет
if __name__ == "__main__":
    main()
```

```python
"""Окно приложения «Тепловая защита сервопривода» (Tkinter)."""

import tkinter as tk                       # основная библиотека окон
from tkinter import ttk, messagebox        # ttk - современные виджеты, messagebox - диалоги

from servo_model import ProtectedServo, ALARM   # классы модели (сами они tkinter не используют)


class ServoApp(tk.Tk):
    """Главное окно. Наследует tk.Tk, хранит ссылку на модель, передаёт ей команды
    и отображает её состояние. Расчётов модели в этом классе нет."""

    # ----- константы окна -----
    DT = 0.1            # период таймера, с (раз в 0.1 с вызывается _tick)
    TIME_SCALE = 5      # ускорение: за один тик модель считает 0.1 * 5 = 0.5 с
    HIST_LEN = 300      # сколько последних точек температуры хранить для графика
    W, H = 360, 170     # размер холста (Canvas), пикселей
    T_MIN, T_MAX = 20.0, 100.0   # диапазон шкалы графика по температуре, °C

    COLOR_OK = "#2e9d3a"      # зелёный цвет индикатора «НОРМА»
    COLOR_ALARM = "#d62828"   # красный цвет индикатора «АВАРИЯ»

    def __init__(self, servo):
        super().__init__()                      # создаём само окно (конструктор tk.Tk)
        self.title("Тепловая защита сервопривода")
        self.resizable(False, False)            # размер окна менять нельзя
        self.servo = servo                      # ссылка на объект модели
        self.history = []                       # список температур для графика
        self.running = False                    # идёт ли моделирование (кнопка «Старт / Пауза»)
        self.was_alarm = False                  # была ли авария на прошлом тике (чтобы предупредить один раз)
        # Связанные переменные: при их изменении виджеты обновляются сами
        self.current_var = tk.DoubleVar(value=0.0)    # значение ползунка тока
        self.entry_var = tk.StringVar(value="0.0")    # текст в поле ввода тока
        self.info = tk.StringVar()                    # строка состояния внизу окна
        self._build_widgets()                   # создаём все виджеты
        self._redraw()                          # первая отрисовка
        self.after(int(self.DT * 1000), self._tick)   # запускаем таймер: через 100 мс вызвать _tick

    # ---------- создание виджетов ----------
    def _build_widgets(self):
        # Холст для графика температуры, слева (колонка 0)
        self.canvas = tk.Canvas(self, width=self.W, height=self.H, bg="white")
        self.canvas.grid(row=0, column=0, padx=5, pady=5)

        # Рамка с элементами управления, справа (колонка 1)
        panel = ttk.LabelFrame(self, text="Управление")
        panel.grid(row=0, column=1, sticky="n", padx=5, pady=5)

        # Ползунок тока: от 0 до max_current, связан с current_var,
        # при перемещении вызывает _on_scale
        ttk.Label(panel, text="Ток, А:").pack(anchor="w")
        self.scale = ttk.Scale(panel, from_=0.0, to=self.servo.max_current,
                               variable=self.current_var,
                               command=self._on_scale)
        self.scale.pack(fill="x", pady=3)

        # Поле ввода тока с клавиатуры; по Enter и по кнопке вызывается _on_entry
        ttk.Label(panel, text="Ввод тока, А:").pack(anchor="w")
        entry = ttk.Entry(panel, textvariable=self.entry_var, width=10)
        entry.pack(fill="x")
        entry.bind("<Return>", self._on_entry)       # привязка события «нажат Enter»
        ttk.Button(panel, text="Применить",
                   command=self._on_entry).pack(fill="x", pady=2)

        # Кнопки управления моделированием
        ttk.Button(panel, text="Старт / Пауза",
                   command=self._toggle).pack(fill="x", pady=2)
        self.btn_reset = ttk.Button(panel, text="Сброс аварии",
                                    command=self._reset_alarm)
        self.btn_reset.pack(fill="x", pady=2)
        ttk.Button(panel, text="Полный сброс",
                   command=self._full_reset).pack(fill="x", pady=2)

        # Индикатор температуры (полоса от 0 до T_MAX)
        ttk.Label(panel, text="Температура:").pack(anchor="w", pady=(8, 0))
        self.bar = ttk.Progressbar(panel, maximum=self.T_MAX, length=140)
        self.bar.pack(fill="x")

        # Индикатор состояния: цвет фона Label меняется по состоянию защиты
        self.lamp = tk.Label(panel, text="НОРМА", fg="white",
                             bg=self.COLOR_OK, font=("Arial", 12, "bold"))
        self.lamp.pack(fill="x", pady=8)

        # Строка состояния под всем окном; текст берётся из переменной self.info
        ttk.Label(self, textvariable=self.info).grid(row=1, column=0,
                                                     columnspan=2)

    # ---------- обработчики событий ----------
    def _on_scale(self, value):
        """Ползунок сдвинули: передаём значение в модель."""
        try:
            self.servo.current = round(float(value), 2)       # сеттер модели проверит диапазон
            self.entry_var.set(f"{self.servo.current:.2f}")   # синхронизируем поле ввода
        except (ValueError, RuntimeError):
            # модель отказала (например, авария) - возвращаем ползунок к реальному значению
            self.current_var.set(self.servo.current)

    def _on_entry(self, _event=None):
        """Ток введён с клавиатуры: разбираем текст и передаём в модель."""
        try:
            text = self.entry_var.get().strip().replace(",", ".")   # «4,5» -> «4.5»
            try:
                value = float(text)                   # превращаем текст в число
            except ValueError:
                # текст не число - заменяем системное сообщение на понятное
                raise ValueError("Введите число, например 4.5") from None
            self.servo.current = value                # проверка диапазона - внутри свойства модели
            self.current_var.set(value)               # двигаем ползунок
        except (ValueError, RuntimeError) as err:
            messagebox.showerror("Ошибка", str(err))  # окно с ошибкой, программа продолжает работать
            self.entry_var.set(f"{self.servo.current:.2f}")   # возвращаем последнее принятое значение

    def _toggle(self):
        """Кнопка «Старт / Пауза»: переключаем флаг моделирования."""
        self.running = not self.running

    def _reset_alarm(self):
        """Кнопка «Сброс аварии»: просим модель снять аварию."""
        try:
            self.servo.reset_alarm()                  # модель сама проверит, остыл ли привод
        except ValueError as err:
            messagebox.showerror("Сброс невозможен", str(err))
        self._redraw()

    def _full_reset(self):
        """Кнопка «Полный сброс»: всё в исходное состояние."""
        self.running = False
        self.servo.reset()
        self.current_var.set(0.0)
        self.entry_var.set("0.0")
        self.history.clear()                          # стираем график
        self.was_alarm = False
        self._redraw()

    def _tick(self):
        """Таймер моделирования: вызывается каждые DT секунд через after().
        Цикла с sleep нет, поэтому окно не «замораживается»."""
        if self.running:
            self.servo.step(self.DT * self.TIME_SCALE)    # один шаг модели
            self.history.append(self.servo.temperature)   # запоминаем температуру для графика
            del self.history[:-self.HIST_LEN]             # оставляем только последние HIST_LEN точек
            # авария возникла именно на этом тике?
            if self.servo.state == ALARM and not self.was_alarm:
                self.current_var.set(0.0)                 # ток обнулён моделью - показываем это
                self.entry_var.set("0.0")
                self._redraw()
                messagebox.showwarning(
                    "Тепловая защита",
                    "Перегрев! Привод обесточен, выполнен аварийный останов")
            self.was_alarm = self.servo.state == ALARM    # запоминаем состояние для следующего тика
            self._redraw()
        self.after(int(self.DT * 1000), self._tick)       # планируем следующий вызов (замыкаем цикл)

    # ---------- отрисовка ----------
    def _y(self, temp):
        """Переводит температуру в координату y на холсте (0 - верх, H - низ)."""
        frac = (temp - self.T_MIN) / (self.T_MAX - self.T_MIN)   # доля от 0 до 1 по шкале
        return self.H - 10 - frac * (self.H - 20)                # чем жарче, тем выше

    def _redraw(self):
        """Перерисовывает холст и обновляет индикаторы по текущему состоянию модели."""
        cv, s = self.canvas, self.servo
        cv.delete("all")                              # стираем старый рисунок
        # красная пунктирная линия - порог аварии
        cv.create_line(0, self._y(s.t_trip), self.W, self._y(s.t_trip),
                       fill="red", dash=(4, 2))
        cv.create_text(5, self._y(s.t_trip) - 8, anchor="w", fill="red",
                       text=f"порог {s.t_trip:.0f} °C")
        # оранжевая пунктирная линия - температура, при которой разрешён сброс
        cv.create_line(0, self._y(s.t_reset), self.W, self._y(s.t_reset),
                       fill="orange", dash=(4, 2))
        cv.create_text(5, self._y(s.t_reset) - 8, anchor="w", fill="orange",
                       text=f"сброс {s.t_reset:.0f} °C")
        # синяя линия - график температуры по накопленной истории
        if len(self.history) > 1:
            step = self.W / self.HIST_LEN             # ширина одной точки по горизонтали
            pts = [v for i, t in enumerate(self.history)
                   for v in (i * step, self._y(t))]   # плоский список x1, y1, x2, y2, ...
            cv.create_line(*pts, fill="blue", width=2)
        alarm = s.state == ALARM
        self.bar["value"] = s.temperature             # заполняем полосу температуры
        # индикатор: текст и цвет по состоянию
        self.lamp.config(text=s.state,
                         bg=self.COLOR_ALARM if alarm else self.COLOR_OK)
        # при аварии ползунок блокируется (менять ток нельзя)
        self.scale.state(["disabled"] if alarm else ["!disabled"])
        # кнопка «Сброс аварии» доступна только при аварии
        self.btn_reset.state(["!disabled" if alarm else "disabled"])
        self.info.set(str(s))                         # строка внизу берётся из __str__ модели


def main():
    """Создаёт модель и окно, запускает главный цикл."""
    servo = ProtectedServo("SERVO-1", t_trip=80.0, t_reset=60.0)
    app = ServoApp(servo)       # окно получает ссылку на модель
    app.mainloop()              # главный цикл: ждёт события и вызывает обработчики


# main() запускается только при прямом запуске файла
if __name__ == "__main__":
    main()
```

## 6. Выводы

В ходе лабораторной работы разработано приложение «Тепловая защита сервопривода» с оконным интерфейсом на Tkinter. Модель реализована двумя связанными наследованием классами: `Servo` описывает нагрев привода, а `ProtectedServo` добавляет аварийный останов при достижении 80 °C и сброс аварии после остывания до 60 °C. Инкапсуляция обеспечена свойством `current` с проверкой диапазона и защищёнными атрибутами температуры и признака аварии. Полиморфизм достигнут переопределением методов `_check_allowed()`, `_after_step()` и свойства `state`: один и тот же метод `step()` для `Servo` не ограничивает нагрев, а для `ProtectedServo` обесточивает привод. Логика модели вынесена в отдельный модуль без `tkinter`, что позволило проверить её запуском файла: при токе 4 А температура устанавливается около 57 °C, при 6 А защита срабатывает через 72,2 с. Окно `ServoApp` содержит `Canvas`, `Scale`, `Entry`, `Button`, `Progressbar`, `Label`; состояние обновляется через `after()` без блокировки окна, а некорректный ввод обрабатывается через `try/except` с выводом сообщения в `messagebox`.
