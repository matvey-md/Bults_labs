## Теоретическая часть

**Цель работы:**

Знакомство с принципами работы интерпретатора Python, настройка переменной окружения PATH [5.2], изучение основных возможностей среды разработки VS Code [6.2], правил построения логических и физических строк [7.9], понятий переменных [7.5] и констант [7.2], а также способов форматированного вывода данных методом format() [7.4.6].

**Краткие теоретические сведения:**

Python относится к интерпретируемым языкам программирования: перед выполнением исходный код преобразуется в промежуточное представление — байт-код, обработку которого выполняет виртуальная машина Python [4.1.6]. Переменная в Python не является областью памяти, а представляет собой имя, ссылающееся на объект, размещённый в динамической памяти [7.8.1, 12.7]. Для выделения логических блоков программы используются отступы величиной 4 пробела, соблюдение которых является обязательным условием корректной работы кода [7.10]. Форматированный вывод данных реализуется с помощью метода format(), построенного в соответствии со спецификацией PEP 3101 [7.4.6]. Например, запись `'{0:.3f}'.format(pi)` выводит вещественное число, округлённое до трёх знаков после десятичной точки [7.4.6]. Более компактной альтернативой методу format() являются f-строки, позволяющие подставлять значения переменных непосредственно внутрь строкового литерала.

## Практическая часть

**Задание:** Составить программу, вычисляющую значение физической величины по заданной формуле. Все переменные должны быть динамически привязаны к вводимым значениям. Результат вычисления округлить до 4 знаков после запятой. Исходные данные ввести с помощью функции `input()`. В качестве вычисляемой величины рассматривается гидростатическое давление столба жидкости P = ρ·g·h.

**Код программы:**

```python
p = float(input("Введите плотность жидкости (p): "))
g = float(input("Введите ускорение свободного падения (g): "))
h = float(input("Введите высоту столба жидкости (h): "))
P = p * g * h
print(f"Гидростатическое давление: {round(P, 4)}")
```
