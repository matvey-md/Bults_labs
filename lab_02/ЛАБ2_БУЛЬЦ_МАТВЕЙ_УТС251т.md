## Теоретическая часть

**Цель работы:**

Изучение основ структурного программирования на языке Python: определение и вызов функций [8.4], передача параметров и возврат значений [8.5], условный оператор if [8.1], цикл с предусловием while [8.2], а также форматированный вывод данных с помощью f-строк [7.4.6]. Практическое применение полученных знаний для моделирования процесса заполнения резервуара.

**Краткие теоретические сведения:**

Функция — именованный блок кода, который может принимать параметры и возвращать результат оператором return [8.4]. Если функция возвращает несколько значений, они автоматически упаковываются в кортеж (tuple), который при вызове можно распаковать в отдельные переменные [8.5]. Строка документации (docstring), заключённая в тройные кавычки, описывает назначение функции, её параметры и возвращаемое значение. Условный оператор if позволяет выполнить блок кода только при истинности заданного условия; в программе он используется для проверки корректности входных данных, а досрочный return прерывает выполнение функции [8.1]. Цикл while повторяет тело цикла, пока его условие остаётся истинным [8.2]. Для корректной работы цикла значение, входящее в условие, должно изменяться внутри тела, иначе цикл станет бесконечным. Конструкция `if __name__ == "__main__"` позволяет выполнять тестовый блок только при непосредственном запуске файла, но не при его импорте как модуля. Для форматированного вывода применяются f-строки: спецификатор `{x:.2f}` выводит вещественное число с двумя знаками после запятой [7.4.6].

## Практическая часть

**Задание:** Написать функцию, моделирующую заполнение резервуара жидкостью. На каждой итерации в резервуар добавляется фиксированный объем жидкости; заполнение прекращается, когда текущий объем достигает 95 % от максимального. Функция должна проверять корректность входных данных и возвращать итоговый объем и количество выполненных итераций. Результаты вывести с форматированием.

**Код программы:**

```python
def fill_tank_simulation(v_max, v_inc):
    if v_inc <= 0:
        return 0, 0
    if v_max <= 0:
        return 0, 0
    current_volume = 0.0
    iterations = 0
    target_volume = 0.95 * v_max
    while current_volume < target_volume:
        current_volume += v_inc
        iterations += 1
    return current_volume, iterations


if __name__ == "__main__":
    v_max_input = 1000.0
    v_inc_input = 120.0
    total_volume, num_iterations = fill_tank_simulation(v_max_input, v_inc_input)
    print(f"Максимальный объем: {v_max_input} л")
    print(f"Шаг добавления: {v_inc_input} л")
    print("-" * 30)
    print(f"Итоговый объем: {total_volume:.2f} л")
    print(f"Количество итераций: {num_iterations}")
```
