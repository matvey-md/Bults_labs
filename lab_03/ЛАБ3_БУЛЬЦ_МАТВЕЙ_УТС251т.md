## 2. Краткие теоретические сведения

**Модуль:** отдельный файл с расширением `.py`, содержащий определения функций, переменных и классов. Модульная архитектура обеспечивает повторное использование кода и декомпозицию сложных программных комплексов. Для подключения модуля используется оператор `import module`, для импорта отдельных функций — форма `from module import function`.

**Точка входа `__name__`:** при импорте модуля весь его код исполняется один раз. Чтобы отделить код тестирования от используемого функционала, применяется проверка `if __name__ == '__main__':`. Блок выполняется только при прямом запуске файла, но не при его импорте.

**Системный модуль sys:** предоставляет доступ к параметрам среды исполнения. Список `sys.argv` содержит аргументы командной строки: `sys.argv[0]` — имя запускаемого скрипта, `sys.argv[1]`, `sys.argv[2]`, ... — параметры, переданные через пробел при запуске. Это позволяет менять настройки программы без редактирования исходного кода.

**Структуры данных:** список (list) — упорядоченная изменяемая последовательность; кортеж (tuple) — упорядоченная неизменяемая последовательность; словарь (dict) — набор пар «ключ: значение» с уникальными ключами; множество (set) — неупорядоченная коллекция уникальных элементов.

**Срезы:** синтаксис `[start:stop:step]`, где start — начальный индекс (включительно), stop — конечный индекс (не включительно), step — шаг. Отрицательные индексы отсчитываются от конца последовательности, а срез со `step = -1` разворачивает последовательность в обратном порядке.

## 3. Задание (Вариант №5)

Контроль качества нефтепродуктов на НПЗ. При компаундировании товарных топлив проводится экспресс-анализ кинематической вязкости и состава примесей. Образцы с некорректной вязкостью забраковываются, а уникальные виды примесей заносятся в паспорт качества.

Разработать модуль `variant5_mod.py` со следующими функциями:

1. `check_viscosity_range(samples, min_v=2.0, max_v=8.0)` — отбраковывает замеры вязкости вне допуска списковым включением;
2. `group_by_grade(oil_dict)` — группирует пробы из словаря по сортам топлива;
3. `get_unique_impurities(impurity_lists)` — объединяет списки примесей нескольких проб в множество (set).

Разработать главный скрипт `variant5_main.py`, который считывает верхний предел вязкости из `sys.argv[1]` (по умолчанию 7.0), формирует данные лабораторных проб, выполняет фильтрацию и группировку, вызывает функции модуля и выводит паспорт качества.

## 4. Исходный код программы

**Файл модуля `variant5_mod.py`:**

```python
"""Модуль контроля качества нефтепродуктов (вариант 5)."""


def check_viscosity_range(samples, min_v=2.0, max_v=8.0):
    """Отбраковывает замеры вязкости вне допуска [min_v; max_v]."""
    # Списковое включение: берём каждое значение x из samples
    # и оставляем его, только если оно лежит между min_v и max_v
    good = [x for x in samples if min_v <= x <= max_v]
    return good  # возвращаем список годных замеров


def group_by_grade(oil_dict):
    """Группирует пробы по сортам топлива.

    oil_dict: словарь вида {номер_пробы: (сорт, вязкость)}.
    Возвращает словарь вида {сорт: [номера проб]}.
    """
    groups = {}  # пустой словарь для результата
    for sample_id, info in oil_dict.items():  # перебираем пары «ключ: значение»
        grade = info[0]  # сорт топлива - первый элемент кортежа
        if grade not in groups:  # если такого сорта в результате ещё нет
            groups[grade] = []  # создаём для него пустой список
        groups[grade].append(sample_id)  # добавляем номер пробы в список сорта
    return groups  # возвращаем сгруппированный словарь


def get_unique_impurities(impurity_lists):
    """Объединяет списки примесей нескольких проб в множество."""
    unique = set()  # пустое множество (дубликаты в нём исчезают сами)
    for lst in impurity_lists:  # перебираем списки примесей каждой пробы
        unique.update(lst)  # добавляем все примеси списка в множество
    return unique  # возвращаем множество уникальных примесей


# Блок автономной проверки модуля: выполняется только при прямом запуске файла,
# при импорте из другого файла он не срабатывает
if __name__ == '__main__':
    test_samples = [1.8, 3.2, 4.5, 6.8, 9.1, 5.0]
    test_oil = {'P-1': ('АИ-92', 3.2), 'P-2': ('АИ-95', 4.5), 'P-3': ('АИ-92', 6.8)}
    test_imp = [['water', 'sulfur'], ['sulfur', 'sand']]
    print("Фильтрация:", check_viscosity_range(test_samples, 2.0, 7.0))
    print("Группировка:", group_by_grade(test_oil))
    print("Примеси:", get_unique_impurities(test_imp))
```

**Файл главного скрипта `variant5_main.py`:**

```python
import sys  # модуль sys нужен для чтения аргументов командной строки
from variant5_mod import check_viscosity_range, group_by_grade, get_unique_impurities  # функции нашего модуля


def main():
    # Верхний предел вязкости: если аргумент передан - берём его (sys.argv[1]),
    # иначе используем значение по умолчанию 7.0
    if len(sys.argv) > 1:
        max_visc = float(sys.argv[1])  # аргументы приходят строками, переводим в число
    else:
        max_visc = 7.0

    # Исходные данные лабораторных проб
    samples = [1.8, 3.2, 4.5, 6.8, 9.1, 5.0]  # список замеров вязкости
    impurities = [['water', 'sulfur'], ['sulfur', 'sand'], ['water', 'paraffin']]  # примеси по пробам
    # Словарь проб: номер пробы -> (сорт топлива, вязкость)
    oil = {
        'P-1': ('АИ-92', 3.2),
        'P-2': ('АИ-95', 4.5),
        'P-3': ('АИ-92', 6.8),
        'P-4': ('ДТ', 5.0),
        'P-5': ('АИ-95', 6.1),
    }

    # Вызов функций модуля
    clean = check_viscosity_range(samples, 2.0, max_visc)  # фильтрация замеров
    groups = group_by_grade(oil)  # группировка проб по сортам
    unique_imp = get_unique_impurities(impurities)  # множество уникальных примесей

    # Вывод паспорта качества
    print("=== ЛАБОРАТОРНЫЙ АНАЛИЗ НЕФТИ ===")
    print(f"Предел вязкости (sys.argv): {max_visc}")
    print(f"Исходная выборка вязкости: {samples}")
    print(f"Очищенная выборка вязкости: {clean}")
    print("Группировка проб по сортам топлива:")
    for grade, ids in groups.items():  # перебираем сорта и списки проб
        print(f" - {grade}: {ids}")
    print(f"Уникальные примеси (set): {unique_imp}")


# Точка входа: main() запускается, только если файл запущен напрямую
if __name__ == '__main__':
    main()
```
